# Модуль конфигурации

### Содержимое конфигурации
#### Блок `window` - настройки окна приложения
- `width` - фиксированная ширина окна
- `height` - фиксированная высота окна
- `title` - заголовок окна
- `background` - путь до файла с фоном приложения
#### Блок `animaltion` - настройки поведения анимаций 
- `duration_ms` - продолжительность всех анимаций в миллисекундах
- `notification_hide_after_ms` - продолжительность демонстрации уведомения (для тех уведомлений, которые скрываются автоматически)
#### Блок `network` - базовые настройки подключения
- `base_transfer_timeout_ms` - продолжительность ожидания ответа от сервера

### Расположение конфигурационных файлов
По-умолчанию, приложение ищет конфигурационный файл по пути стандартного расположения конфигураций ОС. Для линукс это `$HOME/.config/ICLDrive`

Для того, чтобы в процессе разработки изменить место расположения конфигурационного файла приложения, ожидаемое системой, необходимо передать его с помощью переменной `FORCED_APPLICATION_CONFIG_PATH`. Например:
```sh
cmake -s $SOURCES_DIR -DFORCED_APPLICATION_CONFIG_PATH:FILEPATH=/home/user/ApplicationConfig.yaml
```
Для того, чтобы в процессе разработки изменить место расположения конфигурационного файла подключения, ожидаемое системой, необходимо передать его с помощью переменной `FORCED_NETWORK_CONFIG_PATH`. Например:
```sh
cmake -s $SOURCES_DIR -DFORCED_NETWORK_CONFIG_PATH:FILEPATH=/home/user/NetworkConfig.yaml
```
